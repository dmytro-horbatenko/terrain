# Terrain learning context

Call `get_learning_context` for current Terrain evidence. Pass `topic` only when the user names a specific topic; otherwise omit it.

When the user pastes a Terrain learning-session export, keep that export authoritative for the session target, Session ID, chosen approach, source plan, conduct, and output contract. Use the tool's result only to add current prior-learning evidence, prerequisites, blockers, and roadmap alternatives.

Treat the tool as read-only. Do not claim to record reviews, edit topics, conduct sessions, or change progress through this plugin.
