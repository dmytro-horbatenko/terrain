# Topic note

Copy the useful parts into the topic's editable **Terrain note**. Delete headings
that add no value; keep one explanation current instead of collecting summaries.

## Question and explanation

What problem does this concept solve? Explain it in your own words. Add a small
diagram, derivation or trace when it makes the mechanism clearer.

## Conditions and invariants

What must be true for the explanation or algorithm to hold? Name relevant units,
state, trust, time and rounding assumptions. What remains unchanged?

## Example and failure case

Show one small worked example and one changed input or counterexample. Explain
why the result changes. Include the misconception you corrected.
