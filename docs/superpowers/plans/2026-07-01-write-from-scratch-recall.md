# Write-from-Scratch Code Recall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a `Prompt` be marked `promptKind: 'code'` so its review-flow recall step shows a real code editor (CodeMirror) instead of a plain textarea, while every existing/`'concept'` prompt is unaffected.

**Architecture:** One additive `String @default("concept")` column on `Prompt`, threaded through the import contract (`packages/types`) → import persistence (`apps/api` `ImportService`) → export authoring instructions (`OUTPUT_CONTRACT`) → web read path (`apps/web` `Prompt` type + `ReviewGate`). No new endpoints, no change to `POST /reviews`, no execution/grading of what's written.

**Tech Stack:** Prisma 7 (Postgres, driver adapter), NestJS 11, Zod, React 19, `@uiw/react-codemirror` (new dependency) for the code scratch area.

## Global Constraints

- No in-app LLM calls, no code execution/grading of what's written in the editor (spec: Out of scope).
- The code/text written in the recall scratch area stays ephemeral — never sent in the `POST /reviews` payload, cleared on prompt rotation (spec: Web review flow).
- `promptKind` is a plain Prisma `String`, not an enum (spec: Data model — matches `packages/types`' string-union convention for `ReviewMode`/`TopicStatus`).
- Existing `Prompt` rows and any `proposedPrompts` entry omitting `promptKind` must default to `'concept'` with zero UI change (backward compat).
- Repo convention: no git commits unless the user explicitly asks (`CLAUDE.md`) — the steps below say "commit" per the skill template, but treat that as "stage the diff for review," not an actual `git commit`, unless told otherwise.

- [ ] **Step 3: Render CodeMirror for `'code'` prompts in `ReviewGate`**

Replace the full contents of `apps/web/src/components/ReviewGate.tsx`:

```tsx
import { useEffect, useState, type ReactNode } from 'react';
import CodeMirror from '@uiw/react-codemirror';
import { keymap } from '@codemirror/view';
import { indentWithTab } from '@codemirror/commands';
import { useNextPrompt } from '../api/hooks';

const tabKeymap = keymap.of([indentWithTab]);

/** Gates review submission behind a recall-then-reveal step when the topic
 *  has a due prompt. Falls back to rendering `children` immediately when
 *  the topic has none, so today's review flow is unaffected. */
export function ReviewGate({
  topic,
  children,
}: {
  topic: { id: string };
  children: (promptId?: string) => ReactNode;
}) {
  const { data: prompt, isLoading } = useNextPrompt(topic.id);
  const [revealed, setRevealed] = useState(false);
  const [scratch, setScratch] = useState('');

  useEffect(() => {
    setRevealed(false);
    setScratch('');
  }, [prompt?.id]);

  if (isLoading) return null;
  if (!prompt) return <>{children()}</>;

  return (
    <div className="col gap-3">
      <div className="card card-pad col gap-2">
        <div className="card-title" style={{ margin: 0 }}>
          Recall
        </div>
        <div>{prompt.promptText}</div>
        {!revealed && (
          <>
            {prompt.promptKind === 'code' ? (
              <CodeMirror
                value={scratch}
                onChange={setScratch}
                extensions={[tabKeymap]}
                height="160px"
                placeholder="Write the solution before revealing (not saved)"
              />
            ) : (
              <textarea
                className="textarea"
                style={{ minHeight: 56 }}
                placeholder="Try to answer before revealing (not saved)"
                value={scratch}
                onChange={(e) => setScratch(e.target.value)}
              />
            )}
            <button className="btn btn-primary right" onClick={() => setRevealed(true)}>
              Reveal
            </button>
          </>
        )}
        {revealed && prompt.answerHint && <div className="faint">{prompt.answerHint}</div>}
      </div>
      {revealed && children(prompt.id)}
    </div>
  );
}
```
